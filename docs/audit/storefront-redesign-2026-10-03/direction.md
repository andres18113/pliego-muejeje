# PLIEGO public storefront redesign

Direction: a contemporary bookseller, with the visual energy of printed book jackets and a folded sheet. Real cover art is the imagery; no invented merchandise, reviews, promotions or availability claims.

Palette: Ultramar #283da8; Tinta #252740; Lavanda #e4def4; Papel #f6f5f0; Amarillo #f3df83; Blanco #ffffff. Dark mode uses #22243b for reading surfaces and #f0edf8 for text while keeping the colored editorial panels.

Typography: Bricolage Grotesque Variable for the wordmark and editorial headings; Roboto Flex Variable for reading, navigation, prices and form controls. Sentence case, left alignment, readable measures.

Desktop composition:
[ PLIEGO | catálogo + subjects                     search/cart/account ]
[ large blue typographic opening      | actual covers on lavender     ]
[ books to discover                 rail controls + full catalog link ]
[ real book covers, titles, authors, prices and commerce actions       ]
[ choose a subject: philosophy / literature / mathematics             ]
[ literary focus: large cover        | actual title/author + category  ]
[ blue bookstore footer with clear destinations                       ]

Mobile composition:
[ menu | PLIEGO                              search/cart/account ]
[ blue headline + browse action                                  ]
[ lavender book display                                          ]
[ horizontally browsable, keyboard accessible bookshelf          ]
[ vertically composed subject panels                             ]
[ literary cover + title, stacked                                ]

Catalog: colored title band and persistent subject navigation, followed by a readable product grid; topic filters open on desktop, a focus-trapped filter drawer on smaller screens. Product controls and URL behavior retain their existing commerce implementations.

Review against brief: avoid the cream/serif/clay default, identical rounded cards, repeated rails and purely decorative labels. Boldness belongs to the opening and subject panels; the shopping grid stays disciplined so covers are the focus. Motion responds to browsing and deliberate interactions; reduced motion disables it.

Approved root baselines and database/backend contracts are untouched. This document describes the new frontend direction authorized for this task and supersedes visual choices only for the public storefront.
